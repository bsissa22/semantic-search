# Gami.ai - Gamification Marketing Platform

A complete gamification marketing SaaS platform inspired by Winday.co.

## Repository
GitHub: https://github.com/mahdi1234-hub/Gami.ai

## Live Demo
Deployed: https://gami-ai-smoky.vercel.app

## Features
- 6 game types (Bubble Shooter, Match-3, Draw-a-Line, Shooting Range, Scratch Card, Spin Wheel)
- Campaign builder with multi-step wizard
- Analytics dashboard with charts
- Leaderboard system
- Player management
- Reward/coupon management
- Embed & QR code generator
- Brand settings, team management, billing
- Gmail SMTP email verification
- Config-driven game system
- iFrame sandbox pattern for game isolation
